# 小记与 JSON 数据协议

小记采用轻量的连续正文布局。顶部中央默认只显示当前标签（默认「全部」），悬停后向下浮出彩色标签页与新增加号，不移动正文。标签按可用宽度自动换行，加号始终占用右侧独立列并垂直居中，长标签截断显示。标签过多时限制浮层高度，仅滚动标签区，加号保持可见。选择后收起；移出整块区域延迟收起，支持点击和原有右键管理、长按排序。日期保留点击菜单，不显示下箭头。默认在「全部」中追加的小记归入「未归类」；在具体标签中追加时使用当前标签。标签可右键重命名、设置颜色或删除，长按标签约 0.28 秒后拖动可调整顺序，由原生鼠标跟踪直接完成，不依赖跨视图拖放。悬停滑块直接复用日历的 `HoverTrackingView` 和 `HoverSpring`，遵循相同动效与减少动态效果设置。

删除标签前展示其全部日期下关联的记录数，可选择转移到另一个标签，或只移除标签关联、保留正文。无剩余关联的条目进入「未归类」；已有的其他标签关联保留。删除标签从不删除正文。一条小记支持多个标签，列表中只显示一次，默认在条目右上角只显示分类色点，移入显示三个点，展开设置后显示标签名称并可直接更换；导出保留所有标签说明。

条目按日期、预计时间排序，同一天未设置时间的条目按追加顺序放在末尾，不再按标签分块。每条记录默认只展示正文、完成圆圈和分类色点，不显示标签文字。鼠标移入时色点位置显示三个点，展开菜单后可查看名称、单选更换分类或进入多标签设置。完成圆圈与首行文字使用相同的行高与顶部偏移。无时间和日期信息时不创建底栏，也不保留进度占位。左滑完整露出删除区域后松手才弹出删除确认，短滑回弹；也可在记录菜单中删除。

顶部清单图标进入批量操作模式，此时才显示多选框、全选及批量工具。范围由当天／全部日期及标签共同决定，切换筛选清空选择。批量完成、取消完成、移动标签、删除均可撤销。

## 书写与自动保存

正文默认完整显示，点击进入编辑，点击别处自动提交、保存并退出编辑，不需要“完成编辑”。编辑框随内容增长，整个页面统一滚动，只有手动折叠才收起内容。每条的折叠按钮放在行尾，移入时以叠加方式显示，不增加行高；无进度时使用行尾的悬停折叠入口。右上角支持当前视图全部折叠／全部展开。右下角固定加号追加新条目，不随正文滚出视图。没有内部固定高度的正文滚动框。文本展示支持简单 Markdown：标题、段落、粗体、斜体、列表、引用、代码与链接，不加载远程图片或网页组件。

输入停顿 400 毫秒后自动保存，连续输入合并写入；切换标签不会丢失修改。关闭编辑器、收起日历、退出应用前立即保存。没有保存或取消按钮，⌘S 保留为立即保存的兼容入口，不关闭页面。新条目正文空白、未选标签、未设时间且未标记完成时，只在编辑中临时存在，不写入存储；移出编辑后自动清理。选择了标签、时间等的条目会保留。

⌘Z／⇧⌘Z 撤销／重做文本及清单操作，⌘X/C/V/A 为原生剪切／复制／粘贴／全选文本，⌘N 追加。正文内 ⌘1—6 设置／切换对应级别的标题，⌘0 恢复普通段落；⌘B 粗体、⌘I 斜体、⌘U 下划线（使用 `<u>…</u>`）、⌘E 或 ⌘` 行内代码。选中文字后包裹标记，再次按下可移除；未选择文字时插入标记并将光标放在中间。下划线支持预览及 PDF 导出。按住 Command 350 毫秒显示快捷键浮层，松开隐藏。清单全选仅在批量模式出现。

每条记录的菜单可设置预计完成时间，只显示北京时间 HH:mm。当天未完成的记录在条目右侧显示自绘玻璃沙漏，通过上、下沙量表示进度。沙漏靠近分类色点，中心与色点对齐；悬停显示 HH:mm，点击可修改时间，不显示百分比。颜色从很浅的灰蓝随经过比例连续过渡到橙色、红色，完成后不显示进度。其计算方式为：从实际添加时刻 `createdAt` 到预计时间计算经过的比例，不再因为跨日而改用当天零点，过去和未来日期不显示。时间在该日创建时刻之前时，过期后显示满进度；完成的记录隐藏沙漏。

## 导出

小记使用独立的原生可调整大小窗口，拖动窗口边缘调整尺寸并记忆到本地；右上角低调的恢复图标重置为 470 × 570。内容延伸到原生标题栏区域，减少顶部空白；按钮有不改变布局的平滑悬停反馈。普通正文编辑与阅读采用相同的字号、行距，去掉输入框额外内边距和最小高度占位；拖动过程中按当前布局宽度实时重新测量正文、刷新换行，高度不再依赖旧宽度；尺寸仅在结束调整后持久化。

顶部展开工具中的钉子可将小记独立置顶，关闭日历或点击其他应用时仍保留。可拖动窗口顶部移动位置，置顶状态与位置会记忆到本地；右上角关闭图标始终可以明确关闭小记。原先顶部的对号已移除，“小记”标题的悬停提示显示自动保存状态，失败时显示警示图标。

右上角下载图标支持 PDF、Markdown、JSON。导出前可选择包含起止日期的时间范围（或全部日期），并多选标签及未归类；匹配任一选中标签的记录会纳入，同一条只导出一次，并显示匹配条数。默认按当前日期／标签初始化，可扩大范围；批量选择记录时则在选中记录内继续筛选。另提供全部 JSON 备份入口。导出前立即保存草稿。保存位置选择框在当前屏幕居中，以高于日历和小记的窗口层级展示。PDF 使用系统 CoreText 排版与分页，有页眉、页脚、页码和分类标题；Markdown 保留原文语法、日期、完成状态及预计时间。导出不受手动折叠影响，始终包含完整正文。

不增加第三方依赖，不调用浏览器和网络服务。PDF 使用系统字体的中文回退支持。

## 简洁显示与工具栏

右上角默认显示左箭头与关闭。悬停箭头时展开工具，离开整行顶部区域才收起；工具中可切换简洁／完整显示，选择保存在本地。简洁显示隐藏完成圈、预计时间与进度，正文使用释放的宽度，批量编辑仍可操作完成状态。

完整显示把自绘沙漏放在分类色点左侧，不显示百分比。已完成隐藏沙漏，非当天记录不计算进度。关闭、标签加号、条目色点及底部追加按钮共用右侧对齐线。条目悬停使用淡色原生玻璃与弹簧滑块，四周保留相同的 8pt 内边距，长正文按实际条目区域定位，取消指针引起的边框偏移与尺寸拉伸。正文折射使用系统 Core Image 的局部透镜变形，对实际渲染字形采样，不再整体缩放文字。仅获取小记自身可见文字区域的纹理，移动时复用，不访问桌面或其他应用。指针静止不刷新，鼠标离开即释放纹理；快帧最多 60Hz，较慢设备降低到 30Hz。编辑、减少动态效果和关闭动效时停用。没有增加第三方库或资源包。

## 存储与结构

在 UserDefaults 的 `notes.v3` 键中保存 UTF-8 JSON Data，JSON 导出使用相同结构。当前全部日期仍共用一个 JSON；存储时移除格式缩进、合并连续输入的写入，并避免保存时重复解码，导出时恢复易读的缩进。导出菜单可查看当前总记录数和存储大小。纯文本通常体积较小，但长期大量积累仍会增加整份编码、加载和写入开销，进一步扩展适合采用按月分片及独立索引。

```json
{
  "schemaVersion": 3,
  "tags": [
    { "id": "10000000-0000-0000-0000-000000000001", "name": "生活", "color": "green" }
  ],
  "entries": [
    {
      "id": "20000000-0000-0000-0000-000000000001",
      "date": "2026-10-24",
      "text": "今晚去散步",
      "tagIDs": ["10000000-0000-0000-0000-000000000001"],
      "isCompleted": false,
      "dueMinutes": 1110,
      "createdAt": "2026-10-24T10:00:00Z",
      "updatedAt": "2026-10-24T10:00:00Z"
    }
  ]
}
```

标签和条目使用稳定 UUID；标签重命名与排序不修改关联。`tags` 数组顺序就是标签页顺序，`entries` 顺序就是条目顺序。`color` 为可选颜色名，`dueMinutes` 为可选的当天分钟数（0—1439），例如 1110 表示 18:30；省略表示未设置。`date` 是北京时间民用日期，时间戳使用 UTC ISO 8601。修改文本、完成状态或标签关联更新 `updatedAt`，撤销恢复原内容和时间。

## 兼容和迁移

优先读取 v3，没有 v3 时读取 v2 并迁移到 v3，保留 v2 的原始数据。v2 缺失的颜色按已知标签名补齐，缺失预计时间默认为未设置，所有 ID、正文、状态与顺序保持。更早的 v1 日期字符串字典按日期迁移为未归类记录，保留原文与换行，原始 v1 字典保留。

无法解码、版本未知、ID 重复、标签关联无效或预计时间越界时禁止覆盖保存，保留原始数据并允许原样 JSON 导出。不会把读取失败当作空文档写回。导出采用原子写入。

后续不兼容变更须升级 `schemaVersion`，提供明确迁移函数及回归检查。迁移前保留原始版本。降级到旧应用后的编辑不会自动合并回新版本。

## 悬浮、置顶与范围

日历底部固定展示「小记」字样，重复点击同一天入口可开关小记。小记窗口边缘的三角指向日历；日历隐藏时指向标记隐藏。点击置顶会立即关闭日历，保留独立小记，置顶图标在工具栏收起时仍可见；重新打开日历时恢复指向标记。

日期文本或顶部展开工具的日历图标可打开范围选择器。支持当天、本周、本月、全部、自定义起止日期，也可选指定月份或指定日期所在周；周一至周日为一周，起止日期都包含。多日记录按日期分组，日期标题在每组左上方独立成行，组内保持预计时间与追加顺序。范围选择与分类、批量操作组合使用，导出默认继承当前范围。新增记录使用所选日期（多日范围使用锚定日期）。

仅一行的记录不显示折叠入口，也不会被全部折叠操作收起。多行记录的折叠箭头与最后一行文字垂直居中。
